# BookTrans — 영어 PDF를 한국어로 옮기는 오프라인 번역기

BookTrans는 영어 원서 PDF를 한국어로 번역하는 Windows 프로그램입니다.

- 번역은 PC 안에서만 이루어집니다.
- 계정, API 키, 유료 번역 서비스가 필요 없습니다.
- 처음 한 번 번역 모델 파일을 설치하면, 그 뒤로는 인터넷 없이 동작합니다.

## 결과물

번역할 때 아래 세 가지 형식 중 원하는 것을 고를 수 있습니다.

| 파일 | 형태 |
| --- | --- |
| `이름.ko.pdf` | 원래 페이지 배치를 유지하고, 영어 문단 자리에 한국어를 넣은 PDF |
| `이름.en-ko.pdf` | 왼쪽에 원문 페이지, 오른쪽에 번역 페이지를 나란히 놓은 대조 PDF |
| `이름.en-ko.md` | 문단마다 원문과 번역을 번갈아 적은 텍스트 |

## 지원 환경

- **대상 OS**: Windows 10/11 64비트(x64)
  - 개발자의 자동 빌드·시험은 GitHub Actions의 Windows Server 이미지에서만 이루어집니다.
  - 일반 Windows 10/11 PC에서의 동작과 프로그램 화면(GUI)은 자동 시험으로 확인되지 않습니다.
- **미지원**: 32비트 Windows, ARM 전용 Windows, Windows 7/8.1
- **메모리**: 4GB 이상 권장. 번역 중 BookTrans가 약 0.5GB를 씁니다(빌드 서버 측정값: 최대 440~470MB).
- **디스크 공간**: 설치 파일 약 45MB, 설치된 프로그램 약 170MB, 번역 모델 약 370MB, 번역 기록 캐시(사용량에 따라 증가)
- **속도**: 빌드 서버(4코어 CPU)에서 한 문장씩 번역할 때 문장당 약 0.08초였습니다. PC 성능에 따라 다릅니다.

## 처음 실행할 때: 번역 모델 준비 (최초 1회)

번역 모델은 설치 파일에 들어 있지 않습니다. 처음 번역을 시작하면 프로그램이 모델을 내려받아도 되는지 묻고, **"예"를 눌렀을 때만** 내려받습니다.

- **모델**: quickmt 프로젝트의 `quickmt-en-ko`(영어→한국어 전용, 약 1억 8,500만 매개변수, CTranslate2 형식)
- **파일 이름**: `booktrans-model-quickmt-en-ko.zip`
- **설치 방법**: 자동(동의 후 내려받기), 또는 프로그램의 **"모델 파일 설치…"** 버튼으로 받아 둔 파일을 고릅니다. 명령줄에서는 `BookTrans.exe --download-model`(동의 질문) 또는 `BookTrans.exe --install-model 파일경로`입니다.
- **무결성 확인**: 파일의 SHA-256이 프로그램에 고정된 값과 같을 때만 설치합니다. 다르면 설치하지 않습니다.
- **저장 위치**: `%LOCALAPPDATA%\BookTrans\models`
- **내려받는 곳**: `https://github.com/yudeuksong/BookTrans/releases/download/quickmt-en-ko-a32fa39/booktrans-model-quickmt-en-ko.zip` (약 279MB, 최초 1회 인터넷 필요)
  - 이 Release 파일은 BookTrans 저장소의 자동 작업이 공개된 모델에서 다시 만들어, 해시가 고정값과 같을 때만 올린 것입니다.
- **직접 설치**: 인터넷이 막힌 PC에서는 위 주소에서 받은 파일을 다른 경로로 옮긴 뒤 설치할 수 있습니다. 같은 SHA-256 검사를 거칩니다.

### 모델 파일은 어떻게 만들어지나

- 공개된 모델(`quickmt/quickmt-en-ko`, 리비전 `a32fa395ebc7b722a0c021e213ca5fec4065c5df`)을 받아, quickmt 라이브러리가 읽는 파일만 그대로 묶습니다. 모델 자체는 바꾸지 않습니다. 소스의 `packaging/build_quickmt_model.py`가 이 작업을 합니다.
- 같은 파일로 두 번 묶어 결과가 바이트 단위로 같은지 확인합니다. 그 해시가 프로그램에 고정된 값입니다.
- BookTrans의 번역 경로가 공식 quickmt 라이브러리와 같은 토큰을 쓰고 같은 번역을 내는지 빌드 서버에서 자동으로 확인합니다(`packaging/check_quickmt_engine.py`).

### 모델 라이선스에 대해

- Hugging Face의 모델 정보에 **CC BY 4.0**(크리에이티브 커먼즈 저작자표시 4.0 국제)으로 명시되어 있습니다. 출처를 밝히면 상업적 이용과 재배포가 허용됩니다.
- 모델 파일 안에 `ATTRIBUTION.txt`(저작자, 출처, 라이선스, 변경 사항), `MODEL_CARD.md`(모델 카드 원문), `PROVENANCE.txt`(파일별 SHA-256)가 들어 있습니다.
- 모델은 BookTrans가 만든 것이 아니라 quickmt 프로젝트의 자료입니다.

## 사용법

### 프로그램 화면

1. 시작 메뉴에서 **BookTrans**를 실행합니다.
2. **원서 PDF**에서 번역할 파일을 고릅니다.
3. **저장 폴더**를 고릅니다. 비워 두면 PDF와 같은 폴더에 저장합니다.
4. 필요하면 **페이지 범위**를 적습니다. 예: `1-20,25`
5. **출력 형식**을 고르고 **번역 시작**을 누릅니다.
6. 끝나면 **결과 폴더 열기**를 누릅니다.

로그 창에는 건너뛴 문장, 중복 문장, 재사용한 번역 수가 표시됩니다. 같은 책을 다시 번역하면 이전 번역을 재사용해 더 빠릅니다.

### 명령줄

```text
BookTrans.exe --install-model booktrans-model-quickmt-en-ko.zip   모델 파일 설치(최초 1회)
BookTrans.exe 책.pdf --pages 1-10 -o 결과폴더
BookTrans.exe --about                     저작권·라이선스 고지
```

## 품질과 한계

- **번역 품질**: PC에서 도는 작은 오프라인 모델(185M)이라 상용 번역 서비스보다 품질이 낮습니다. 모든 결과는 기계 번역이므로, 중요한 내용은 원문과 함께 확인하세요.
- **문단 단위로 다시 묶은 뒤 번역**: PDF의 줄바꿈은 문장 경계가 아니므로, 같은 단의 줄을 문단으로 다시 묶은 뒤 번역합니다.
  - 제목, 목차, 머리글·쪽 번호는 따로 둡니다.
  - 다른 단의 글은 이어 붙이지 않습니다.
  - 줄 끝에서 하이픈으로 나뉜 단어는 다시 합칩니다.
  - 쪽을 넘어 이어지는 문단은 한 문단으로 번역한 뒤 두 쪽에 나눠 넣습니다.
  - 모든 대문자로 된 제목은 일반 문장 형태로 바꿔 모델에 보냅니다.
- **자동 검사**: 문장마다 다음을 검사합니다.
  - 빈 결과, 같은 말 반복, 지나친 누락
  - 숫자가 빠지거나 바뀐 경우(예: eighteenth → 8)
  - 부정문이 긍정문이 되거나, "not only … but"이 부정문이 된 경우
  - 번역되지 않고 남은 영어 단어
  - 원문과 관계없는 웹 문구(예: "관련 기사", "계정 관리")
- **검사에 걸린 문장 처리**
  - 다시 번역해 보고, 그래도 안 되면 **원문(영어)으로 남깁니다.**
  - 그 문단에는 PDF에서 노란 표시와 메모(사유와 기계 번역 후보)가, `.md`에서는 `⚠ 검토 필요` 표시가 붙습니다.
  - 검사에 걸린 번역은 캐시에 저장하지 않습니다.
- **자동 검사의 한계**: 문법은 자연스럽지만 뜻이 틀린 번역은 잡지 못할 수 있습니다. 검사를 통과했다고 번역이 정확하다는 뜻은 아닙니다.
- **결과 상태**: 번역이 끝나면 `이름.report.json`과 화면 메시지로 다음을 알려 줍니다.
  - 번역된 문단 수
  - 원문으로 남긴 문장 수
  - 스캔 페이지
  - 자리가 부족했던 문단
  - 명령줄 종료 코드는 0(모두 완료), 7(완료했지만 확인 필요), 8(번역된 문단 없음)입니다.
- **OCR은 지원하지 않습니다.** 글자가 이미지로만 들어 있는 스캔 PDF는 번역할 수 없고, 해당 페이지 번호를 알려 줍니다.
- **배치와 표**: 번역문이 원래 칸보다 길면 아래 빈 공간으로 늘리고, 그래도 부족할 때만 글자를 줄입니다. 수식, 표, 세로쓰기 글자는 원문을 그대로 둡니다.
- **암호가 걸린 PDF**는 지원하지 않습니다.

## 저장되는 데이터와 삭제 방법

BookTrans는 아래 위치에만 데이터를 저장합니다. 프로그램을 지워도 이 폴더는 남습니다.

| 경로 | 내용 |
| --- | --- |
| `%LOCALAPPDATA%\BookTrans\models` | 번역 모델 |
| `%LOCALAPPDATA%\BookTrans\memory.sqlite3` | 번역 기록 캐시: 원문 문장과 검사를 통과한 번역문. 번역한 책의 문장이 들어 있습니다. 0.1.2는 이전 버전이 저장한 번역을 다시 쓰지 않습니다(파일은 지우지 않음) |
| `%LOCALAPPDATA%\BookTrans\last-error.log` | 마지막 명령줄 오류 기록 |

모두 지우려면 BookTrans를 닫고, 탐색기 주소창에 `%LOCALAPPDATA%\BookTrans`를 입력해 그 폴더를 삭제하세요. 모델도 함께 지워지므로, 다시 쓰려면 모델 파일을 다시 설치해야 합니다.

## 설치 파일 확인과 SmartScreen 안내

- 설치 파일은 **코드 서명이 되어 있지 않습니다**. 그래서 Windows SmartScreen이나 백신이 "알 수 없는 게시자" 경고를 보여 줄 수 있습니다.
- 내려받은 파일이 배포된 파일과 같은지는 `SHA256SUMS`로 확인할 수 있습니다. PowerShell에서 아래 명령을 실행해, 나온 값이 `SHA256SUMS`의 값과 같은지 비교하세요.
  ```powershell
  Get-FileHash .\BookTrans-Setup-0.1.2.exe -Algorithm SHA256
  ```
- 해시가 같다는 것은 "배포된 파일과 같은 파일"이라는 뜻일 뿐입니다. 프로그램이 안전하다는 보증은 아닙니다. 출처를 신뢰할 수 있을 때만 실행하세요.
- SmartScreen, Microsoft Defender 같은 Windows 보호 기능은 끄지 마세요.
- 자동 시험은 빌드 서버에서 명령줄 번역과 모델 파일 설치·내려받기 거부 과정만 확인합니다. 실제 PC에서의 설치 과정과 프로그램 화면 동작은 자동 시험 대상이 아닙니다.

- **설치 파일(결합 배포물)**: [GNU AGPL-3.0](LICENSE)
  - PDF 처리에 쓰는 PyMuPDF/MuPDF가 AGPL-3.0(또는 Artifex 상용 라이선스)으로 배포되기 때문입니다.
- **BookTrans 자체 소스 코드**: 위 AGPL과 함께 [MIT](LICENSE-MIT)로도 제공됩니다.
- **포함된 제3자 구성 요소**: 설치 폴더의 `THIRD_PARTY_NOTICES.txt`와 `licenses\` 폴더에 정리되어 있습니다. 각 릴리스의 `BookTrans-ThirdParty-Source` ZIP에는 그 빌드에 쓰인 구성 요소의 소스 압축 파일과 수집 내역(`SOURCES_MANIFEST.txt`)이 들어 있습니다.
- **번역 모델**: BookTrans에 포함되지 않습니다. 모델의 라이선스는 위 "모델 라이선스에 대해"를 보세요.

## 직접 빌드하기

```bash
cd booktrans
python -m venv .venv
.venv/Scripts/pip install --require-hashes -r packaging/requirements-lock.txt
.venv/Scripts/pip install --no-deps -e .
.venv/Scripts/python -m pytest
```

Windows 설치 파일은 `.github/workflows/booktrans.yml`과 같은 순서로 만듭니다(PyInstaller → 라이선스 수집 → Inno Setup).
