# BookTrans 0.1.2 (비공개 시험판)

영어 PDF를 한국어로 번역하는 오프라인 Windows 프로그램입니다. 계정이나 API 키가 필요 없고, 번역 모델 파일을 한 번 설치한 뒤에는 인터넷 없이 PC 안에서만 번역합니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `BookTrans-Setup-0.1.2.exe` | Windows 10/11 x64용 설치 파일. 관리자 권한 없이 설치할 수 있습니다 |
| `BookTrans-Portable-0.1.2.zip` | 설치 없이 압축을 풀어 쓰는 판 |
| `BookTrans-Source-0.1.2.zip` | BookTrans 소스 코드, 빌드·설치 스크립트, 잠긴 의존성 목록 |
| `BookTrans-ThirdParty-Source-0.1.2.zip` | 포함된 제3자 구성 요소의 소스와 수집 내역(`SOURCES_MANIFEST.txt`) |
| `SHA256SUMS` | 위 네 파일의 SHA-256 |
| `booktrans-model-quickmt-en-ko.zip` | 번역 모델 파일(약 279MB). 프로그램과 따로 받습니다 |

## 0.1.1 이후 바뀐 점

- **번역 모델을 quickmt-en-ko로 바꿨습니다.**
  - quickmt 프로젝트의 영어→한국어 전용 모델이며 라이선스는 CC BY 4.0입니다. 모델 파일 안에 출처 표기(ATTRIBUTION.txt), 모델 카드, 파일별 해시가 들어 있습니다.
  - 공개된 파일을 바꾸지 않고 묶었습니다. 두 번 묶어 같은 파일이 나오는지 확인한 뒤 SHA-256 `2ef78d406cddf53fa621db0a5ec66a6cb8745932ec25a6d976fe94df6efda7cd`로 고정했습니다.
  - BookTrans의 번역 결과가 공식 quickmt 라이브러리와 같은지 자동으로 확인합니다(시험 문장 29개 모두 동일).
  - 빌드 서버 비교(문장 25개, 같은 실행): 의미 검사 통과 개발용 5/7, 처음 보는 문장 16/18. 이전 후보 m2m100_418M은 5/7, 14/18이었고 문장당 0.84초, 메모리 967MB였습니다(quickmt 0.14초, 440MB).
- **처음 번역할 때 동의를 받은 뒤 모델을 내려받습니다.** 내려받는 곳은 BookTrans 저장소의 Release(`quickmt-en-ko-a32fa39`)이며, 고정된 SHA-256과 같을 때만 설치합니다. 인터넷이 없는 PC에서는 같은 파일을 "모델 파일 설치…" 버튼이나 `--install-model`로 설치할 수 있습니다.
- PDF 크기 문제(글꼴 중복)를 고쳤습니다. 시험용 3쪽 책의 결과 PDF가 약 61~65KB입니다.
- 줄을 문단으로 다시 묶어 번역합니다(제목·목차·머리글 분리, 하이픈 단어 합치기, 쪽을 넘는 문단 이어 번역).
- 자동 검사를 강화했습니다. 숫자, 부정, "not only … but", 의무·명령("must"), 남은 영어, 지어낸 웹 문구·"(주)" 같은 오류가 의심되는 문장은 번역 대신 영어 원문으로 두고 노란 표시를 합니다.
- 결과 폴더에 `이름.report.json`(번역 통계와 검사에 걸린 문장 목록)을 함께 저장합니다.

## 알아 두실 점

- **필요한 PC**: 메모리 4GB 이상 권장(번역 중 약 0.5GB 사용), 디스크는 프로그램 약 130MB와 모델 약 346MB.
- **속도**: 빌드 서버(Windows, 4코어)에서 시험용 3쪽 책(문장 62개, 실제 번역 36개)이 프로그램 시작 포함 약 7초 걸렸습니다.
- **번역 품질**: 기계 번역입니다. 시험용 책의 의미 검사 9개 중 7개가 통과했고, 나머지 2개는 자동 검사가 걸러 영어 원문으로 남겼습니다(틀린 번역이 그대로 보인 경우 0개).
  - 짧은 제목에서 모델이 "가사 보기", "강좌", "제품 소개" 같은 웹 문구를 지어내는 경우가 있습니다. 자동 검사가 이런 문장을 걸러 영어로 남기므로, 제목이 영어로 남는 경우가 있습니다. 시험용 책에서는 62문장 중 8곳(서로 다른 문장 6개)이 영어로 남았습니다.
  - 자동 검사를 통과했지만 어색한 번역도 있습니다(예: PROBLEM → "문제 해결 방법").
- **OCR 미지원**: 스캔 이미지로만 된 PDF는 번역하지 않습니다.
- **무서명 설치 파일**: SmartScreen 경고가 나올 수 있습니다. `SHA256SUMS`로 확인하고, Windows 보호 기능은 끄지 마세요.
- **시험 범위**: GitHub Actions의 Windows Server와 인터넷이 끊긴 깨끗한 Windows 컨테이너에서 명령줄 동작을 확인했습니다. 실제 Windows 10/11 PC의 설치 과정과 프로그램 화면은 자동 시험하지 않았습니다.
