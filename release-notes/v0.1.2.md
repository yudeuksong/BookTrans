영어 PDF를 한국어로 번역하는 오프라인 Windows 프로그램입니다. 계정이나 API 키가 필요 없고, 번역 모델을 한 번 준비한 뒤에는 인터넷 없이 PC 안에서만 번역합니다.

## 설치 방법

1. 아래 **Assets**에서 둘 중 하나를 받습니다.
   - `BookTrans-Setup-0.1.2.exe`: 설치 파일 (Windows 10/11 64비트, 관리자 권한 불필요)
   - `BookTrans-Portable-0.1.2.zip`: 설치 없이 압축을 풀어 쓰는 판
2. BookTrans를 실행하고 원서 PDF를 고른 뒤 **번역 시작**을 누릅니다.
3. 처음 한 번은 번역 모델을 내려받아도 되는지 묻습니다. **예**를 누르면 [모델 Release](https://github.com/yudeuksong/BookTrans/releases/tag/quickmt-en-ko-a32fa39)에서 약 279MB를 받아, SHA-256이 고정값과 같을 때만 설치합니다.
   - 인터넷이 막힌 PC: 그 Release의 `booktrans-model-quickmt-en-ko.zip`을 다른 경로로 옮겨 **모델 파일 설치…** 버튼으로 고릅니다(압축을 풀지 마세요).

설치 파일은 코드 서명이 없어 SmartScreen 경고가 나올 수 있습니다. 받은 파일은 `SHA256SUMS`로 확인할 수 있습니다. Windows 보호 기능은 끄지 마세요.

## 파일

| 파일 | 설명 |
| --- | --- |
| `BookTrans-Setup-0.1.2.exe` | Windows 설치 파일 |
| `BookTrans-Portable-0.1.2.zip` | 설치 없이 쓰는 판 |
| `BookTrans-Source-0.1.2.zip` | BookTrans 소스 코드, 빌드·설치 스크립트, 잠긴 의존성 목록 |
| `BookTrans-ThirdParty-Source-0.1.2.zip` | 포함된 제3자 구성 요소의 소스와 수집 내역 |
| `SHA256SUMS` | 위 네 파일의 SHA-256 |

## 알아 두실 점

- **필요한 PC**: 메모리 4GB 이상 권장(번역 중 약 0.5GB 사용), 디스크는 프로그램 약 130MB와 모델 약 346MB.
- **속도**: 빌드 서버(Windows, 4코어)에서 시험용 3쪽 문서가 프로그램 시작 포함 약 7초 걸렸습니다. PC 성능에 따라 다릅니다.
- **번역 품질**: PC에서 도는 소형 기계 번역입니다. 시험 문장 9개 중 7개가 의미 검사를 통과했고, 2개는 자동 검사가 걸러 영어 원문으로 남겼습니다. 짧은 제목은 모델이 웹 문구("가사 보기", "강좌" 등)를 지어내는 경우가 있어 영어로 남는 일이 있습니다. 중요한 내용은 원문과 함께 확인하세요.
- **자동 검사**: 숫자·부정·의무 표현·남은 영어·지어낸 문구 등 오류가 의심되는 문장은 영어 원문으로 두고 노란 표시를 합니다. 뜻이 틀렸지만 자연스러운 번역은 잡지 못할 수 있습니다.
- **OCR 미지원**: 스캔 이미지로만 된 PDF와 암호가 걸린 PDF는 번역하지 않습니다.
- **시험 범위**: 이 저장소의 `release-build` 작업이 빌드 서버의 Windows와 인터넷이 끊긴 Windows 컨테이너에서 명령줄 동작(모델 내려받기·설치·번역)을 확인했습니다. 실제 Windows 10/11 PC의 설치 과정과 프로그램 화면은 자동 시험하지 않았습니다.
